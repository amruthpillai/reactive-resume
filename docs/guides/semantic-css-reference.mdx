Reactive Resume Semantic CSS (RRSS) is a versioned, declarative stylesheet language for resume PDFs. It resembles CSS,
but only the syntax and PDF-safe capabilities documented here are supported.

## Version directive

Start authored stylesheets with:

```css
@rr-version 1;
```

Version 1 remains immutable. A missing directive is accepted with a warning and interpreted as version 1; unsupported
versions are rejected.

## Selectors

RRSS supports semantic type selectors, `#id`, attribute selectors, descendant/child/adjacent/general-sibling
combinators, selector lists, `:root`, `:is()`, `:where()`, `:not()`, `:first-child`, `:last-child`, `:only-child`,
`:nth-child()`, and `:nth-of-type()`.

The semantic tree follows source order. Structural declarations such as `display`, `order`, and page-break behavior are
resolved once without changing the selector tree used by later rules.

Use `[type="experience"]` for portable section-type rules and `[id="…"]` for an exact section or item in one resume.
Known selectors that are absent from the current resume produce warnings rather than errors.

## Declarations and values

The standard cascade, specificity, source order, inheritance, CSS-wide keywords, custom properties, `var()`, and
`!important` are supported within the bounded version-1 grammar. Lengths use the units listed in the generated property
table. Unitless values are accepted only where the property definition allows them.

Pagination maps to React PDF:

- `break-before: page` starts a new page.
- `break-inside: avoid` keeps a node together where possible.
- `-rr-min-presence-ahead` reserves space before the next break.
- `orphans` and `widows` control text line retention.
- `position: fixed` repeats an existing fixed node; CSS cannot create or re-parent content.

Media queries support authored PDF dimensions such as `@media (max-width: 600pt)`.

## Diagnostics and last-valid behavior

Diagnostics include a stable code, severity, message, and source range. The editable source is saved even when invalid.
Preview and export use `applied`, the most recent source that compiled and passed bounded PDF preflight. Correcting the
draft promotes the new source atomically.

## Portability

Shared semantic elements are portable across templates. Template parts are optional manifest entries for visual details
that have no shared semantic equivalent. Guard them with `resume[template="…"]`; absent parts produce a warning.

## Unsupported capabilities

RRSS cannot choose or load fonts, reference local or remote assets, execute scripts, react to interaction, use browser
layout APIs, or create new PDF nodes. CSS Grid, pseudo-elements, animations, transitions, filters, arbitrary functions,
and network-fetching values are unsupported.

Gradients and shadows are not part of version 1. They may be added later only through bounded SVG-backed rendering.
