## M3-T1: Sign-in (Claude Code). Branch `mobile/M3-T1`

**Target:** README §4 M3-T1. A user enters a server (default `https://rxresu.me`), the app validates it through `/.well-known/oauth-authorization-server`, registers itself through DCR (cached per origin in SecureStore, re-registered on `invalid_client`), reads `flags.get` (signups, guest login), signs in through the system browser with PKCE, stores tokens in SecureStore, refreshes them single-flight, signs out (revoke + clear), and handles an expired session with the session-expired banner and a re-sign-in path. Guest login when `flags.allowGuestLogin`.

**Change:** port `mobile/S3:apps/spike-s3` (read with `git show`) into `src/auth/**`, implementing the M1 `session.ts` contract. Follow every rule in ledger "Carry-forward for M3-T1" (resource param, single-flight refresh, DCR body from `reports/S3.md` §1, `preferUniversalLinks`, hand-parsed query strings, no `URLSearchParams.get`). Screens `app/(auth)/server.tsx`, `app/(auth)/sign-in.tsx` per the `app.html` sign-in frames. Route guard: unauthenticated users land on `(auth)`. For local testing the https callback cannot be proven (no public host); use the dev fallback S3 used and record it. Test against a local server (`pnpm dev` from your worktree with an isolated DB; see memory "redesign local verification" pattern: port 5433 Postgres) on iOS simulator and Android emulator.

**Ownership:** `apps/mobile/app/(auth)/**`, `apps/mobile/src/auth/**` (keep the `session.ts` exported signatures), `reports/M3-T1*`.

## M3-T4: Preview pipeline (Codex). Branch `mobile/M3-T4`

**Target:** README §4 M3-T4. The Page tab shows the user's resume rendered on device: `@reactive-resume/pdf/native` + `@reactive-resume/forme-native` → PDF bytes → `modules/pdf-pages` rasterises visible pages to PNG at the needed scale (PDFKit on iOS, `android.graphics.pdf.PdfRenderer` on Android) → `expo-image` crossfade. Scheduler with the web debounce values (100 ms, 250 ms while a field is focused; `preview.browser.tsx:35-38`) and stale-request dropping. Persistent font cache in `expo-file-system` through `configureFontReader`, falling back to the network on disk errors. Images fetched through `expo/fetch` (streaming, so the 12 MB limit holds). Zoom 60–150% and fit, page-map tap overlay that selects an entry (route to `entry/[section]/[item]`), overflow caption with "Fit to one page", lost-characters warning. Parity script in `apps/mobile/scripts/parity` (README §3.7): `sample.ts` × all 17 templates through `@reactive-resume/pdf/server` (Node) and through `/native` on device, comparing page count and per-page text; run it and record results.

**Ownership:** `apps/mobile/modules/pdf-pages/**`, `apps/mobile/src/preview/**`, `apps/mobile/app/builder/[id]/page.tsx`, `apps/mobile/scripts/parity/**`, `packages/pdf/src/native.tsx`, `packages/pdf/package.json` (exports only), `reports/M3-T4*`.
