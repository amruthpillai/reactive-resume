**Ownership:** `apps/mobile/app/(tabs)/documents/**`, `apps/mobile/app/new.tsx`, `apps/mobile/src/features/documents/**`, `reports/M3-T2*`.

## M3-T5: Builder Write (Claude Code). Branch `mobile/M3-T5`

**Target:** README §4 M3-T5 and the Write frames in `mockups/builder.html` (Direction B "Outline first").
