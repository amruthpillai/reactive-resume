## Target

A workspace package `packages/forme-native` (`@reactive-resume/forme-native`, an Expo module). From JavaScript on an iOS simulator and an Android emulator, it renders a Forme document JSON to the same `{ pdf, layout, warnings }` result `@formepdf/core`'s `renderSerializedDocWithLayout` returns. It also exposes a font subsetter with the signature `(font: Uint8Array, text: string) => Uint8Array`. No WASM and no WebView.

## Change

1. **Toolchain.** Install what is missing, user-level only:
   - `rustup target add aarch64-apple-ios aarch64-apple-ios-sim aarch64-linux-android x86_64-linux-android armv7-linux-androideabi`
   - `cargo install cargo-ndk cbindgen`
   - NDK 28.2 is in `~/Library/Android/sdk/ndk`.
   - Record the exact versions in the report.
2. **Rust crate** at `packages/forme-native/rust/`, depending on `forme-pdf = "=0.28.0"` (crates.io; the same version as npm `@formepdf/core` 0.28.0).
   - Read the crate and the npm package's `pkg-web/forme.d.ts` / wasm-bindgen glue to find the exact Rust entry behind `render_pdf_with_layout(json, opts)`.
   - Expose a C ABI, with a header generated by cbindgen:
     - `render_with_layout(json) -> { pdf bytes, layout json, warnings json }`
     - `subset_font(bytes, text) -> bytes`
     - free functions
   - For subsetting, prefer a pure-Rust subsetter (for example typst's `subsetter` crate) if it produces fonts Forme accepts. Otherwise link harfbuzz `hb-subset`. Record which one you used and why.
3. **Builds.** A script `packages/forme-native/rust/build.sh` produces:
   - an iOS `.xcframework` (device arm64 plus simulator arm64)
   - Android `jniLibs` (arm64-v8a, armeabi-v7a, x86_64)
4. **Expo module** (`ios/`, `android/`, `src/index.ts`).
   - Use the Expo Modules API in Swift and Kotlin. Run work off the JS thread and return Promises.
   - Accept the JSON as a string and return the PDF as `Uint8Array`.
   - `src/index.ts` exports `renderSerializedDocWithLayout(doc: Record<string, unknown>)` and `subsetFont(bytes, text)`, typed to match `FormeEngine` / `FontSubsetter`.
5. **Fixture.** Write a throwaway Node script (keep it under `apps/spike-s1/`) that runs the real `packages/pdf` pipeline in Node.
   - Capture the document JSON passed to the engine for `packages/schema/src/resume/sample.ts` with templates `azurill`, `pikachu` and `onyx`.
   - Also capture the WASM result.
   - Save the JSON and the PDFs under `packages/forme-native/fixtures/`.
6. **Prove it.** Use a minimal Expo dev-client app in `apps/spike-s1/`, which is NOT merged.
   - It loads the fixtures, renders them through the module on the iOS 17.4 or 26.x simulator and on an Android emulator, and writes the PDFs out.
   - Create an AVD if none exists.
