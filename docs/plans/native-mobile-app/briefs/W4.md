## M4-T2: Check (Codex). Branch `mobile/M4-T2`

**Target:** README §4 M4-T2 and the Check frames in `mockups/design.html`. ## M4-T3: Share, export and history (Codex). Branch `mobile/M4-T3`

**Target:** README §4 M4-T3 and the Share/History frames in `mockups/design.html`. Public toggle, slug check, copy and native share, QR (`react-native-qrcode-svg`), password, visitor downloads, stats (views and downloads, simple SVG bars). **Ownership:** `apps/mobile/app/builder/[id]/share.tsx`, `apps/mobile/app/builder/[id]/history.tsx` (and nested), `apps/mobile/src/features/share/**`, `apps/mobile/src/features/history/**`, `apps/mobile/src/features/document-menu/**`, `reports/M4-T3*`.
