## M1-T1: `apps/mobile` skeleton (Claude Code)

Branch: `mobile/M1-T1`.

### Target

A developer runs `pnpm --filter mobile ios` / `android` (dev build) and gets the Reactive Resume app shell: every route from README §1.5 exists as a stub screen reachable by its typed href, themed with the Desk & Paper tokens in light and dark, in the Hanken Grotesk / Newsreader fonts, with Lingui strings and RTL support. Every later wave adds screens and logic but **no dependencies** and no new shared contracts beyond the ones listed below.

### Change

1. **App.** Create `apps/mobile` (package name `mobile`) as an Expo SDK 58 app with `expo-router`, New Architecture, Hermes. Copy the Metro/pnpm setup that worked in `apps/spike-s2` (watch folders, resolver, single React copy). `apps/mobile/turbo.json` with tag `app:mobile`. `typecheck` script with `tsgo --noEmit` like the other workspaces; extend `@reactive-resume/config` tsconfig where web does.
2. **Dependencies.** Install everything in README §1.4 plus `expo-crypto`, `expo-dev-client`, `expo-image-picker` (M3-T5 picture), `expo-print` (M4-T3), `expo-clipboard`, `expo-localization`, `expo-linking`, `expo-constants`, `expo-splash-screen`, `expo-status-bar`, `expo-system-ui`, `react-native-safe-area-context`, `react-native-screens`, `@lingui/*` (same majors as web), `@ai-sdk/react` + `ai` (M6-T3, same versions as web), `@orpc/client` and `@orpc/tanstack-query` (same as web), and the workspace packages the app consumes: `@reactive-resume/{api (type-only routers),schema,resume,pdf,forme-native,utils,fonts}`. Decide in M1 between `@gorhom/bottom-sheet` and the Expo UI sheet, and pick the reorderable-list library (README §1.4 leaves both to "M2"; decide now so M2 adds nothing) and record why in the report. Use `catalog:` where a shared range exists. Use `npx expo install` semantics (SDK-58-compatible versions).
3. **Workspace wiring (SV6).** Root `turbo.json`: tag rule `app:mobile` denies `app:server`, `app:web`, `runtime:server`, `runtime:browser`, with the same type-only exception for `@reactive-resume/api/routers` that web uses; tag rule `runtime:native` (for `forme-native`) denies `app:web`, `app:server`, `runtime:server`, `runtime:browser`. Add `mobile` scripts to the root `package.json` only if useful (`dev:mobile`). Update `pnpm-workspace.yaml` catalog only if needed. `packages/forme-native/package.json`: bump peers to `expo ^58`, `react-native ^0.88`, `expo-modules-core ~58` (M1-T2 owns everything else in that package).

Root `app/_layout.tsx` with providers (QueryClient, i18n, theme, safe area, gesture handler root, session). `(tabs)` layout with the five tabs: Documents, Applications, raised "+", Career, Settings (simple version; M2-T2 styles it). 9. **i18n.** Lingui RN setup in `src/i18n/`.     - `src/ui/index.ts`: the primitive list from README §4 M2-T1 (Button, IconButton, TextField, TextArea, SelectSheet, Switch, Segmented, Chip, ChipInput, ListRow, Card, Sheet, ConfirmDialog, Toast, EmptyState, Banner, Avatar, Skeleton, SortableList), each a plain working stub with its final props type.
    - `src/routes.ts`: typed href builders for every route.
    - `src/draft/types.ts`: the `DraftStore` interface (resume and letter drafts; fields M3-T3 needs: data, status, undo/redo, conflict, locked, flush).
    - `src/preview/types.ts`: `RenderRequest`, `RenderedPages`.

Branch: `mobile/M1-T2`.

### Target

Web and server rendering are unchanged.

### Change

1. Apply `docs/plans/native-mobile-app/reports/S2/packages-pdf.patch` **without** the `images.ts` `arrayBuffer()` fallback (Codex review blocker: it buffers unbounded data before the 12 MB check). Keep `readImageBytes` requiring a streaming body; mobile passes `expo/fetch`, so the existing `getReader()` path enforces the limit. If `images.ts` needs an injectable `fetch` for that, add it the same way as `configureFontReader` (a module-level setter), not a React Native import.

Read `browser.tsx` and keep the contract parallel. Document in a comment that the font cache wrapper the app injects must fall back to the network on disk errors.
3. `packages/pdf/package.json`: add `"./native": "./src/native.tsx"`.
4. `packages/forme-native`:
