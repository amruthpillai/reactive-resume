## Change

1. Create a throwaway Expo app in `apps/spike-s2/` (latest stable SDK; check `npx create-expo-app@latest`, record the SDK, RN and React versions). It is NOT merged.
   - Configure Metro for this pnpm monorepo so it resolves `@reactive-resume/pdf`, `@reactive-resume/schema` and their deps through the workspace export maps.
   - Hermes must be the engine.
2. **React versions.** The monorepo catalog has `react ^19.3.0`, `packages/pdf` depends on `react-reconciler 0.34.0`, and Expo pins its own React. Make the PDF reconciler work.
   - Prefer a single React copy if Expo's React works with `react-reconciler 0.34.0`.
   - Otherwise isolate one, and measure the bundle-size cost.
   - Record the decision and the evidence.
3. **Stub engine.** Call `renderResume` with an engine whose `renderSerializedDocWithLayout` captures the document JSON and returns a minimal fake result.
   - Repair passes in `render.ts` need layout. If the fake layout makes the pass logic diverge, capture only the first-pass document and say so.
   - For Node, use the same stub through `tsx` or vitest. Keep that script under `apps/spike-s2/`.
4. **Hermes gaps.** Fix them only inside the spike app: polyfills in the app entry, or Metro aliases. Do NOT edit `packages/pdf`.
   - Collect every needed change to `packages/pdf` as a proposed diff in the report. Known suspects:
     - the `?url` imports exist only in `browser.tsx`, which you must not import
     - `images.ts` uses `response.body.getReader()`
     - `AbortSignal.timeout`
     - `TextDecoder` with `{fatal:true}`
     - `structuredClone`
     - `crypto.getRandomValues` (uuid)
     - `\p{…}` regexes
   - Fetch real fonts and images over the network as the browser path does.
5. Measure the time for the host tree plus `toFormeDocument` on Hermes, in a release build, for `sample.ts` × templates `azurill`, `pikachu`, `onyx`. Use an iOS simulator and an Android emulator, plus a device if one is available. Fonts warm.
6. Measure the JS bundle size (`npx expo export`) with and without the pdf pipeline imported.
