# M1-T2: native PDF adapter and Forme hardening

Status: succeeded. Branch: `mobile/M1-T2`, base `2c9fa7878`. No push.

## Delivered

- Applied S2's PDF patch except its unbounded `arrayBuffer()` image fallback. Images still require a streaming body, stop after 12,000,000 bytes and cancel the reader.
- Added `@reactive-resume/pdf/native`: `renderResumePdf(engine, options)` returns PDF bytes, validates resume data and missing fonts, and reports page maps and lost characters through the same callbacks as the browser adapter. Exports include `FormeEngine`, `PageMap`, `RenderResumePdfOptions`, `configureFontReader`, `downloadFont` and `configureImageFetch`.
- Font loading still defaults to the existing Google-host download/fallback and WOFF conversion. Mobile can install its persistent reader once at startup; the adapter comment requires network fallback on disk errors. `configureImageFetch` lets mobile supply `expo/fetch` without importing React Native or Expo into PDF code.
- Added ready `nativeEngine` to `@reactive-resume/forme-native`. Its inferred type is assignable to the PDF package's exported `FormeEngine`, proven with a temporary TypeScript check. Keeping this structural avoids a new dependency or changes to the M1-T1-owned manifest. It subsets asynchronously, retains browser-generated punctuation/digits, caches prepared data URIs and falls back to full font bytes when subsetting fails.
- Restricted the JSON replacer to `Uint8Array` values specifically at `fonts[].src`. Other byte arrays and existing URI strings keep their prior JSON representation; caller documents are not mutated.
- Android render and subset operations now use a named single-thread executor through Expo's existing `runOnQueue(CoroutineScope)` API. Their bodies and Expo result/error conversion are unchanged. Module destruction cancels its scope and closes its dispatcher. iOS already had a dedicated serial queue.
- Pinned Rust 1.95.0 and all five mobile targets in `rust/rust-toolchain.toml`; pinned cbindgen 0.29.4 with an early build-script check. Added `runtime:native` / `role:rendering` Turbo tags and SDK 58 integration documentation.

Implementation commit: `313efdc0f` — `feat(mobile): add native pdf adapter and harden forme engine`.

## Node/WASM parity reproduction

This ran against real WASM Forme, not a stub. The sample picture's web-relative URL was resolved to the repository JPEG's data URI for both adapters; other sample data stayed unchanged. No unit test or standalone test harness was committed.

```sh
rtk proxy env TSX_TSCONFIG_PATH=packages/pdf/tsconfig.json node --import ./apps/server/node_modules/tsx/dist/loader.mjs --input-type=module <<'JS'
import assert from 'node:assert/strict';
import { readFile } from 'node:fs/promises';
import { createRequire, registerHooks } from 'node:module';
import { pathToFileURL } from 'node:url';
import { renderResumePdf, configureFontReader, downloadFont, configureImageFetch } from './packages/pdf/src/native.tsx';
import { sampleResumeData } from './packages/schema/src/resume/sample.ts';
registerHooks({resolve(s,c,next) { return next(s.startsWith('.') && s.endsWith('.node') ? `${s}.ts` : s,c); }});
const { createResumePdfFile } = await import('./packages/pdf/src/server.tsx');
const requirePdf = createRequire(new URL('./packages/pdf/package.json', import.meta.url));
const forme = await import(pathToFileURL(requirePdf.resolve('@formepdf/core')).href);
const { getDocument } = await import(pathToFileURL(requirePdf.resolve('pdfjs-dist/legacy/build/pdf.mjs')).href);
const data = structuredClone(sampleResumeData);
data.picture.url = `data:image/jpeg;base64,${(await readFile('apps/web/public/photos/sample-picture.jpg')).toString('base64')}`;
let fontReads = 0, imageReads = 0;
configureFontReader((src) => { fontReads++; return downloadFont(src); });
configureImageFetch((...args) => { imageReads++; return fetch(...args); });
const pdf = async (bytes) => {
 const loading = getDocument({ data: bytes.slice(), useSystemFonts: false, verbosity: 0 });
 const document = await loading.promise;
 try {
  const text = [];
  for (let n = 1; n <= document.numPages; n++) text.push((await (await document.getPage(n)).getTextContent()).items.map(i => 'str' in i ? i.str : '').join(''));
  return { pages: document.numPages, text };
 } finally { await loading.destroy(); }
};
for (const template of ['azurill', 'pikachu', 'onyx']) {
 let pageMap, lost;
 const native = await renderResumePdf(forme, { data, template, onPageMap: m => { pageMap = m; }, onLostCharacters: c => { lost = c; } });
 const server = new Uint8Array(await (await createResumePdfFile({ data, template, filename: `${template}.pdf` })).arrayBuffer());
 const actual = await pdf(native), expected = await pdf(server);
 assert.deepEqual(actual, expected);
 assert.equal(pageMap.pages.length, actual.pages); assert(pageMap.nodes.length > 0); assert.equal(lost, undefined);
 console.log(`${template}: native=${actual.pages}, server=${expected.pages}; per-page text and page-map PASS`);
}
assert(fontReads > 0); assert(imageReads >= 3);
console.log('Injected font reader and streaming fetch used: PASS');
JS
```

Injected font reader and streaming fetch used: PASS
