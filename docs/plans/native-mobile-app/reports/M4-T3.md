# M4-T3: Share, export and history

Status: succeeded (task-owned implementation). Branch `mobile/M4-T3`, base `mobile/native-app` @ `2f41c9665`. No push. Implementation commit: `99360bf59` (`feat(mobile): add share exports and version history`).

## Delivered

- Replaced Share and History route stubs with Link / Download / History tabs. Uses Desk & Paper primitives and tokens, native safe areas, scrollable keyboard content, Lingui macros and the existing conflict sheet. Share forms stay within the share-panel width on tablets; historical page and timeline sit beside each other on wide screens.
- Public-link toggle, retained private address, lowercase/dash normalization, 300 ms availability check, collision name and suggestion, automatic checked-address save, retry, Copy, native text/link share, public-page opening, QR, password set/remove confirmation, visitor-download toggle. Copy stays disabled until the address is saved. Locked documents keep sharing controls read-only while allowing copy, QR and downloads.
- Anonymous daily views and downloads over the latest 30 days, last-view timestamp, accessible SVG bars, private/empty/loading/retry states and repeat-download explanation. Existing typed statistics endpoints remain authoritative.
- PDF download and Print render on device through `createPreviewPipeline`, using its PDF bytes with `pages: []` to skip raster work. Export-section filtering matches web; lost characters produce the web warning while export/print continues; missing font files still block rendering. Print passes the PDF file URI to `expo-print`. Offline PDF uses the local draft; the banner explains that fonts/images must already be cached.
- Word, OpenDocument, Markdown and JSON call `rest()` on `/resumes/{id}/exports/{format}` after a successful draft flush. File name validation, loading, error/retry and a PDF fallback are present. The system share sheet provides save/share destinations.
- Linked cover letter comes from the existing Applications query. An active letter draft flushes before export. PDF letters compose and render locally with the sender header and an independent document-language Lingui instance. Other letter formats use `/cover-letters/{id}/exports/{format}`. Both files are prepared before handing either off; they open as two consecutive system share sheets. Linked-letter fetching still needs a connection.
- Export batches live only under task-owned cache directories. They remain available after share/print resolves, because Android recipients can still read them. A later export sweeps only batches older than 24 hours; failures to remove old batches do not block export. No tokens or document content are logged.
- History lists saved versions with explicit loading/errors, names the current state, previews historical pages as images with no edit navigation, and restores after confirmation. The existing server restore writes `before-restore` before replacing data, so the app does not create a duplicate snapshot. After restore, `open(id)` reloads server state and resets the draft baseline/undo history. Named versions have always-visible ⋯ actions for rename/delete, with destructive confirmation.
- Document menu implements rename, duplicate, reversible lock/unlock, native HTML notes, details, history, local Print, and Trash with Undo. Uses Documents operations/error handling and new-document markers. Rename, duplication, locking and Trash flush first. Undo waits for the original mutation/refresh to settle. Notes retain untouched HTML, use the draft focus/coalescing hooks and follow deferred remote replacements after blur.
