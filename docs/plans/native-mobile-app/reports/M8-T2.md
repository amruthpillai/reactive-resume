```sh
cd apps/mobile
CI=1 EXPO_NO_TELEMETRY=1 npx expo export --platform ios --source-maps --output-dir dist/ios --max-workers 2
CI=1 EXPO_NO_TELEMETRY=1 npx expo export --platform android --source-maps --output-dir dist/android --max-workers 2
```

| Local exported payload | iOS | Android |
| --- | ---: | ---: |
| Hermes `.hbc` bytes | 27,225,276 | 27,235,320 |
| `.hbc` gzip level 9 bytes (comparison only) | 8,682,024 | 8,687,440 |
| Runtime asset bytes | 642,716 | 642,330 |
| Bytecode + assets, excluding maps/metadata | 27,867,992 | 27,877,650 |

Source maps (~47 MB after the merge/extracted catalogs) are analysis outputs, not counted as runtime/store payload. Outputs remain ignored. Formats are decimal bytes; compressed comparison is **not** an App Store/Play download-size measurement.

**FormatJS cost:** imports live in `src/polyfills.ts`, loaded first by `index.ts`, not `_layout.tsx`. Source maps on both platforms contain 60 FormatJS modules: 566,936 source bytes / 121,066 gzip bytes when concatenated, including the Locale/PluralRules dependency closure. This is source attribution, not additive/incremental Hermes cost. Exactly **53 plural locale-data modules** cover the app’s 55 catalogs (shared English/Chinese, Portuguese `pt` plus special `pt-PT`). Locale data is already restricted to shipped languages; **saving from locale trimming: 0 bytes**. Kept the existing tested plural implementation; no handwritten rules or polyfill ownership edits.

**Estimated store download, not measured:** iOS roughly **35–60 MB**, Android roughly **30–55 MB** per delivered device architecture, allowing for the ~8.7 MB compressed JS after the merge/extracted catalogs, assets, React Native/Hermes/Expo frameworks and native Forme. The M8-T2a 25.45 MB archive contains both iOS slices and three Android ABIs and is a build input, not a per-device store payload. These broad estimates do not prove the soft ≤50 MB target; either platform could exceed it. Measure App Store Connect thinned size/TestFlight and Play AAB device download size after the coordinator’s release builds, then decide whether any trimming is warranted. Development-client/debug downloads will differ substantially.
