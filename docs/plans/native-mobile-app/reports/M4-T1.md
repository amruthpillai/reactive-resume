## Undo and draft use

- `designWrite(key, mutate, discrete)` (`src/features/design/draft.ts`): taps (segments, swatches, pairings, picks, switches, layout moves, reset, template) are `{ newStep: true }`; continuous controls (slider drags, typing hex/CSS, stepper taps) use `coalesceKey: "design.<key>"`, so one drag is one undo step. The store already drops no-op updates; `moveSection` also refuses a drop back in place so hidden neighbours don't move (found by the scenarios below).
- `useDesignDraft(id)` is the only draft call site: it subscribes to `useResumeStore` and opens the resume only when nobody has (Page closes the draft when the pane switches away, until the layout owns it). It never closes it. **When M2-T2's fix round makes the builder layout own the draft, replace its body with the subscribe-only hook; nothing else changes.** Until then, leaving the builder from Design leaves the store open (saves keep flushing on their debounce; the next `open` closes it), same as the Share modal.

## Decisions and cuts

- Sheet is a plain view with a grabber toggle (as web's `DesignSheet`), not gorhom: it is a pane, never dismissed. Detents are Half and Full.
- Slider and Stepper live in `src/features/design/controls.tsx` (no Slider primitive in `src/ui`; no dependency added). Slider is an `adjustable` accessibility element (swipe up/down steps).
- Not built (no dependency, or needs another owner), each listed under follow-ups: the colour picker's saturation square / hue / alpha sliders (fields take hex or rgba text instead), live font previews in the family list, level preview glyphs and an icon grid (icon names only; `src/ui/icon.tsx` holds a curated set), Format stylesheet (web uses Prettier) and focus mode, the CSS semantic-tree diagnostics (`resolveStylesheet` needs the semantic tree; syntax/fatal compiler diagnostics only), "tap anywhere else to cancel" for template previews (the 3 s timeout cancels), press-and-hold preview on tablet (the layout's page can't see Design's preview state), Lingui plurals avoided (`1 page` / `{n} pages`) because Hermes lacks `Intl.PluralRules`.
- Section titles in Layout use `getResumeSectionTitle` from `@reactive-resume/pdf/section-title` (the title as printed, in the resume's language).
- Tokens only; mockup sizes map to tokens (swatch = `size.button`, track = `space.s1`, thumb = `space.s6`, card = `space.s12 × 2 + space.s4`).
