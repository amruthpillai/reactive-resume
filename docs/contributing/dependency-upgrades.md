# Dependency compatibility

Registry audit: October 18, 2026. Workspace npm dependencies, pnpm, EAS CLI, Docker build pins and GitHub Actions were checked against current releases, including major versions. Rust crates and the generated Android/iOS build stack were checked separately. Compatible npm and CI upgrades are applied; the following versions remain intentional holds.

Expo 58.0.14, React Native 0.88.0, Forme 0.28.0, `harfbuzz-sys` 0.8.0 and all direct Rust library dependencies were already current. Drizzle ORM/Kit remain on the latest normal `rc` tag, `1.0.0-rc.4`; their older npm `latest` tags are not upgrades.

The native HTML editor pins Tiptap 3.27.1. Scoped overrides keep its optional React menus at 3.27.1, fixing their mismatch with its exact core/ProseMirror peers. Web Tiptap remains at 3.32.0.

Cosign CLI is updated to 3.1.3. Explicit legacy signing flags preserve the existing container signature format for Cosign 2 verifiers.

Local verification: frozen install, all workspace typechecks, 1,913 passing tests (76 skipped), production builds, Android/iOS JavaScript exports, Expo dependency validation and Doctor (20/20), peer checks, Knip, lint, formatting, boundaries and Actionlint. No new native build, physical-device check, GitHub CI run or deployment is claimed. Existing database-dependent test skips remain.
